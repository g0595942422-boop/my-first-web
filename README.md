# 我的个人主页

这是一个适合前端初学者练习的简单个人主页项目，使用 HTML、CSS 和 JavaScript 完成。

项目采用大众常见的入门模板风格：浅色背景、蓝色主色、白色卡片、统一字体和统一间距，方便学习和继续修改。

## 页面内容

- 我的介绍
- 技能展示
- 项目列表
- 联系方式

## 文件结构

```text
.
├── index.html   # 网页结构
├── style.css    # 页面样式
├── script.js    # 简单交互
└── README.md    # 项目说明
```

## 如何运行

1. 下载或克隆这个仓库。
2. 用浏览器打开 `index.html`。
3. 修改页面中的文字、邮箱、GitHub 等内容，替换成你自己的信息。

## 学习建议

- 先阅读 `index.html`，了解网页由哪些区域组成。
- 再阅读 `style.css`，观察统一字体、颜色、间距和卡片样式是如何设置的。
- 最后阅读 `script.js`，理解按钮点击和技能卡片点击的简单交互。
